## Crates, features and ownership

`kf-prof` has a safe `no_std` core for wire arithmetic, calibration, histogram,
ring, ledger and record definitions. `prof` (default OFF) adds runtime/file
support; `prof-inject` implies `prof` and is diagnostic-only. No unsafe Rust or
raw/disguised host pointer enters this crate. Any mmap/timestamp primitive lives
in a new `kf-linux-raw/src/prof_unsafe.rs`, behind its own default-OFF `prof`
feature, with a validated safe API and perimeter tests/ratchet update.
No frozen `kayfabe-*` crate is touched or linked by new code.

Each integration crate exposes default-OFF `prof` forwarding its dependencies'
feature. The disabled span/record/ledger façade is `#[inline(always)]` and empty;
all profiler state/clock/TLS/file/source imports are cfg-gated. With `prof` and
no `KF3_PROF_FILE`, entry pays one relaxed bool load then returns. Legacy
`KF3_PROF` keeps its current independent behavior; zero added cost is measured
against candidate-5, not against an imaginary version with legacy counters gone.

Registration, calibration, mmap creation, prefault and buffer allocation happen
before publication, outside a vCPU/drainer operation and outside shared locks.
A producer is single-owner (`!Sync`, no Clone); the aggregator is the sole
consumer. Fixed slots are never recycled while a producer/guard can use them.
The production integration must prove vCPU slot assignment from a host-owned
CPU identity without lazy allocation or registration RMW in a trap. Unbound
threads emit no data and are reported as a coverage gap, never silently counted
as covered. Multiple devices require distinct device/generation integers.

The writer owns private control/cursors/free lists and validates all offsets.
The mapped file is an output mirror, never authority for indices, allocation,
control, or host actions. A hostile reader gets read-only access. Even if bytes
are corrupted, the producer does not import them as input. The aggregator must
use private, typed publication storage or a trusted same-process view with
private cursors, never file-provided geometry. Review this distinction before
implementing the mmap boundary.

## Clock

All exported event and record timestamps are absolute CLOCK_MONOTONIC ns.
Calibration brackets MONOTONIC and MONOTONIC_RAW with invariant-TSC reads;
record midpoint anchors, rational TSC frequency, bracket error and RAW-to-MONO
offset. A timestamp uses a serialized TSC read and integer rational conversion,
with checked u128 intermediates and saturating output. No syscall on publication.
The aggregator remeasures each second; calibration epochs are immutable once
published. Record calibration sequence on every event, so an updated fit never
retroactively rewrites an old timestamp. Rejected/backwards/zero-frequency
calibration is explicit CLOCK_UNAVAILABLE, never zero masquerading as valid.

Invariant/synchronized TSC is a precondition to this fast clock, not assumed
from x86 alone. Test CPU migration/skew and drift off the hot path. On an
unsupported clock, profiling is unavailable with a named diagnostic; boot and
production continue unchanged. A syscall fallback in a vCPU is forbidden.
Header records exact clocks, conversion and measured error; merge propagates
error. Host/broker share MONOTONIC only on the same host/boot.

## Proposed wire v1 (little endian only, offsets in bytes)

All scalar wire values are unsigned, little endian; no native Rust/C struct
serialization, usize, pointer, padding contents, or guest strings. Every
reserved byte is zero. Reader bounds are constants, never header allocations.
A fixed 16 MiB file uses these regions; offsets cannot be changed by a header.

| Per-second circular records | 13635584 | 3141632 | 47 x 65536, remainder reserved |

Event (64 bytes): 0 sequence, 8 monotonic_ns, 16 event tag, 24 state/site
packed as two u32s, 32 argument/id, 40 duration/value, 48 device/generation
packed as two u32s, 56 calibration sequence. Publication writes odd sequence,
release fence, atomic payload stores, then even sequence with Release. Readers
load sequence Acquire, payload atomically, Acquire fence, recheck sequence;
odd or changed means unavailable. In-process concurrent payloads are atomic
words: a seqlock does not legalize a Rust non-atomic data race.
Ring head/tail have separate cache lines in the private producer/consumer
control (the wire cursor fields are diagnostic mirrors only).

Aggregate (640 bytes): 0 sequence, 8 count, 16 total_ns, 24 max_ns,
32 max_arg, 40 flags (SATURATED/LOSS), 48..63 reserved,
64: 65 x u64 histogram buckets (zero, then floor(log2(ns))+1), remainder zero.
Max-argument ties keep the earlier observation. Saturation is explicit and
never wraps. State exact totals are exclusive residence time across transitions;
span duration/max/histogram is inclusive. Nested guards restore their parent
with its original logical entry but a fresh residence-segment start. The live
sample is only current state/site/since; it is not used to estimate exact totals.

Ledger entry (64 bytes): 0 sequence, 8 kind, 16 slot generation,
24 id, 32 birth_ns, 40 device/generation packed, 48 status, 56 close_ns.
The consumer snapshot region uses identical entries. One producer owns each
local slot; cross-thread close is an event to the owner or a separate close
record reconciled by the aggregator. It never mutates another producer's slot.

Per-second record (65536 bytes): 0 sequence, 8 start_ns, 16 end_ns,
24 payload_length (<=65472), 32 record index, 40 dropped events,
48 coverage/lag flags, 56 reserved; 64 onwards canonical UTF-8 JSON record
padded with zero bytes. JSON has bounded arrays and no guest-origin strings.
A source marked unavailable/lost is null/UNKNOWN with its coverage bit clear,
never a measured zero. JSONL carries this same object plus `schema:1`;
one serialized bounded buffer/write per second on the aggregator. Bounded
output file rotation is required; rotation failure stops file emission only.

## Aggregator, reader and reconciliation

One dedicated aggregator per process samples live state every 5 ms and emits
once per second on an absolute monotonic schedule. This is a measurement cadence,
not a production wake/retry timer. It never runs on a vCPU or drainer. Fixed
bounded per-thread work; lag/missed periods are counted, never caught up by an
unbounded burst. Exact state/site aggregates survive ring loss; lost event-level
correlation is explicit. No reader command spins on a stopped writer.

CLI: `tail PATH`, `summary FILE [FROM..TO]`, `window FILE T0 T1`,
`hangs FILE --stuck-ms N`, `merge HOST BROKER [--guest CSV --calibration JSON]`.
All times explicitly MONOTONIC ns. Window reports only retained observations
and open/censored intervals; hangs reports last-update age, stuck site/since,
and overdue ledger entries, with stale/coverage caveats. Reader validates magic,
version/endian/file size/lengths/counts/tags before decoding and imposes fixed
byte/record/depth limits. Truncated/odd/changing/corrupt entries are rejected or
skipped with a bounded diagnostic, never panic or allocated header-size buffers.

Display records guest new-content/flip, copy/tick/tick-source handoff, kms and
tear observations. Guest new-content cannot be inferred merely from a repeated
surface address. Per-frame timestamps and verified content identity feed exact
sorted-gap percentiles: 1% low = 1e9/p99 gap, 0.1% = 1e9/p99.9 gap; max and
strict >33/50/100/250/1000 ms counts. Report sample count and unknown/loss.
Broker's default-OFF C writer uses the same checked byte encoding and header,
recording received/presented/released, credits, feedback and compositor refresh.
A presentation observation correlates a verified content/commit ID, not the
compositor's output sequence. `make check` and `make check-sanitize` are GPU-free.

Guest CSV import admits only fixed event kinds and bounded integers (Present,
vsync, 153/141/4101, bugcheck). Ping-pong calibration over the existing diagnostic
channel records host send/receive MONOTONIC and guest QPC/frequency, minimum-RTT
midpoint offset plus at least half-RTT uncertainty per boot. A coordinator runs
that channel in Part B. Missing/invalid calibration yields UNALIGNED, never an
assumed wall-clock/QPC/TSC equivalence. H1 receives normalized individual events;
a per-second summary cannot invent the timestamps/IDs it requires.

## Failure modes and OPEN

Aggregator death: producers continue bounded stores, ring drops increase, current
state and exact totals stay readable; last-update age identifies stale summaries.
Process kill: shared mapping survives as a file; an odd record remains incomplete,
previous even records remain readable. No promise of storage power-loss durability.
Full rings/tables: count drops, do not overwrite outstanding obligations or wait.
File full: reserve/prefault mapping before enabling; on reservation failure stay
disabled with a diagnostic. JSONL short/error writes disable that sink and record
error privately/mmap; never block publication. Map truncation by an actor allowed
to modify the writer's files is outside a read-only-reader contract; do not claim
SIGBUS immunity. Use create-new owner-controlled files, no symlink following.
Only host-derived timing/counters and bounded guest integer IDs are emitted;
no guest bytes, strings, handles-as-pointers, payloads or unbounded logs.
