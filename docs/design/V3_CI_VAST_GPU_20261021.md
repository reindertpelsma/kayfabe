## Trust boundaries

| Actor / asset | Trusted authority | Hostile/compromised effect |
| --- | --- | --- |
| GitHub issuer and API | Numeric identity, run/commit/PR/review facts | Compromise defeats the approval gate |
| Owner, environment reviewers, branch protection | Deployment and approval | Can bypass the check; record a reason |
| Worker code/deploy account and singleton ledger | Admission, ownership, budgets, sanitization | Compromise exposes the upstream key's full permissions |

| Proposed workflow and PR source | Changeable code | Can lie about tripwire results; cannot choose Worker image/script/caps |
| Broker URL/path locators | Reduce scanning/DoS noise only | Known to the box/onstart reader and broker workflow; disclosure does not grant OIDC/HMAC authority |
| Dedicated Vast secret | Upstream account authority | Theft may affect shared assets; application policy is not upstream key isolation |

## Amendment 3/3b: the box reports hostile data to the Worker

[CODE READ: 2026-10-22 owner decision] This section supersedes the Vast-log/marker verdict path. [CODE READ: token construction implementation] Token syntax is v1.<run_id>.<attempt>.<expiry_seconds>.<base64url_mac>. The MAC is HMAC-SHA256(RUN_TOKEN_SECRET, "v1|" + run_id + "|" + attempt + "|" + sha + "|" + label + "|" + expiry). Fields are canonical ASCII decimal/hex; the MAC is exactly 43 base64url characters. Verify its 32-byte value with native WebCrypto HMAC verification (no JavaScript string comparison of tags) and require matching ledger key, run, attempt, SHA, label, expiry, open state and TTL. Store a hash of the fixed onstart script for ambiguous-create reconciliation, not its embedded bearer. RUN_TOKEN_SECRET and OWNER_STOP_TOKEN are owner-only Worker bindings, never box inputs. The box receives only its derived limited bearer and nonce.

[CODE READ: hostile schema/caps implementation] POST /report/<run> accepts Bearer plus a JSON object with seq, kind (progress/log/result), optional text, and a structured result containing exactly nonce/verdict for result messages. Reject unknown keys, wrong types/enums, invalid nonce charset, non-integer/out-of-range sequence and wrong nesting. Stream at most 64 KiB before parsing; scan structural depth outside strings before JSON.parse. A run admits at most 2000 authenticated report attempts and 4 MiB transport input; retries and malformed reports consume those limits too. Limit authenticated attempts in a fixed 10-second window (default 20), including retries. Owner variables may lower these hard maxima for tests/operations. Gaps in seq are allowed; only an identical digest at the last seq is an idempotent retry; changed duplicates and older seq are rejected. Closure always wins over retries. Raw text never determines verdict: only kind=result with the exact nonce and PASS/FAIL enum can close a result.

[CODE READ: live token implementation] Every report also requires Vast actual_status=running for the recorded owned ID/label, with at most three seconds of cached positive status. Unknown/missing/exited/stopped status, label mismatch, provider error or stale status that cannot be refreshed closes the run and yields the same generic 401 as a bad/unknown/closed/expired bearer. Thus local result/stop/TTL closure revokes immediately; external box termination is detected on the next uncached check, with a documented maximum three-second positive-cache window. Cron checks each open ledger record and retries owned cleanup. A failed deletion keeps its billing reservation; revocation does not imply acknowledged destroy. Reporting before create acknowledgement receives BUSY/retries rather than authorizing an unknown ID.

[CODE READ: data boundary implementation] Decode UTF-8 with replacement, normalise CRLF/CR and Unicode separators to newline, remove ANSI/OSC/C0/C1/format controls except newline/tab, redact known bindings/current bearer and token-shaped strings. Prefix EVERY rendered line with visible [box] text, and render all :: and ##[ delimiters as : : and # #[ before storage; cap each line to 1024 UTF-8 bytes and retained tail to 200 lines/8192 bytes, preserving complete prefixes and code points. Persist only sanitised tail plus dropped-byte accounting. Never use box text as a key, header, URL, filename, Markdown/HTML or status description. No raw report body is logged. Runner output stays inside a fresh random stop-commands frame and never enters summary/env/output channels. Only fixed Worker state/verdict metadata may become job outputs; status descriptions are chosen from a fixed state map. [CODE READ: stop implementation] POST /stop/<run> accepts that run's OIDC or a constant-time-matched OWNER_STOP_TOKEN; POST /stop-all accepts only the owner secret. The box bearer grants neither stop, rent nor status authority. Vast log retrieval is optional diagnostic fallback only, not a dependency and never a verdict source; no fallback is wired by this amendment.

[CODE READ: fixed callback sender implementation] Fixed onstart embeds only validated HTTPS Worker origin, canonical run key, limited bearer, nonce and SHA.
