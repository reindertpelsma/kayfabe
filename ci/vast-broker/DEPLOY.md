# Owner deployment: nine steps

[CODE READ: wrangler.toml, deployment.json, docs/BOX_PROTOCOL.md] The owner deploys. The committed default is `RENTING_ENABLED=false`. Main is `dist/worker.js` with `no_bundle=true`; plain deploy uploads the reviewed bundle. No Cloudflare credentials belong in GitHub.

1. Install Node 22+ and the pinned CLI outside the checkout: `npm install --prefix /tmp/kf-vast-wrangler wrangler@4.152.0`. Authenticate Cloudflare on the owner's machine.
2. In `ci/vast-broker`, run `npm test` and `npm run bundle`. Verify `sha256sum dist/worker.js` equals both manifests and `DEPLOYED_BUNDLE_SHA256` in wrangler.toml. Current bundle: `39401ee4cdcf845bfc83522f46fe8a043da85f4a5390d48d21708fc4db69828a`.
3. Retain public vars `OWNER_GITHUB_ID=229738317`, `REPOSITORY_GITHUB_ID=1311106387`, `REPOSITORY=reindertpelsma/kayfabe`, `APPROVAL_MODE=owner_push_or_review`, `RENT_DRAFTS=false`, `ALLOWED_BASE_BRANCHES=["master"]`, and initially `RENTING_ENABLED=false`. Policy numbers come from defaults.json: price $1/h, daily $6, rolling $30, prepaid reserve $8, boot 40 min, hard 180 min.
4. Retain `OIDC_SUB=repo:reindertpelsma/kayfabe:environment:gpu-vast`, `CHECK_JOB_WORKFLOW_REFS=["reindertpelsma/kayfabe/.github/workflows/gpu-vast.yml@refs/heads/master"]`, and `SWEEP_JOB_WORKFLOW_REF=reindertpelsma/kayfabe/.github/workflows/gpu-vast-sweep.yml@refs/heads/master`. Missing/mismatched job_workflow_ref, subject or numeric IDs refuse before GitHub calls.
5. Keep the SQLite `LEDGER` / `BrokerLedger` binding, initial `v1` migration and `* * * * *` cron from wrangler.toml. Preserve the namespace on updates. Check the disabled upload first with `/tmp/kf-vast-wrangler/node_modules/.bin/wrangler deploy --dry-run`; then deploy with that pinned CLI and the same configuration.
6. Set Worker secrets using that CLI's `secret put`: `WORKER_URL` (exact HTTPS origin, no path), `VAST_API_KEY` (dedicated billed key), `RUN_TOKEN_SECRET`, `OWNER_STOP_TOKEN`, and `BROKER_PATH_PREFIX`. Generate independent signing/owner secrets of 32–256 base64url characters; the prefix must be 32–128 base64url characters and is REQUIRED when renting is enabled. Never print or commit their values. Set WORKER_URL after the disabled deployment establishes its URL.
7. For private blobs, set public `BLOB_REPO=owner/repository` and optional `BLOB_ALLOWED_TAG_PREFIXES` JSON, plus secret `BLOB_GITHUB_TOKEN` with release-asset read access. Production uses the owner's different token, not the local acceptance credential. No App/PAT is needed for basic rent/report/kill; `/blob-url` fails closed without its own store configuration.
8. Put only `VAST_BROKER_URL` (same origin) and `VAST_BROKER_PATH` (prefix alone) in GitHub environment `gpu-vast` secrets. The billed Vast key, signing secret, owner stop token and blob token stay out of GitHub. The BASE runner presents OIDC only. Hosted claim issuance still needs an actual GitHub run; absent job_workflow_ref fails closed. Unauthenticated GitHub fact reads retain their public API rate limit.
9. [CODE READ: wrangler.toml, docs/BOX_PROTOCOL.md] After the chosen approved repository SHA contains the repo-side entrypoint/payload, the owner can set `RENTING_ENABLED=true` and redeploy the same verified bundle. Validate owner stop using `POST /<prefix>/stop-all` with the owner token. Keep the owner stop secret independent of run tokens. Required check and owner-dispatched sweep remain separate profiles.

[CODE READ: defaults.json, policy.js budget checks] Three hours at $1/h is $3 of work, so $6 covers two full work periods arithmetically. Admission additionally reserves one cron minute per run and transfer/storage liabilities: two maximum-rate reservations total $6.033334 before extra transfer, so the second is refused without sufficient daily headroom. These conservative checks are explicit; the shipped caps stay unchanged.

Full KVM image/suite payload, hosted OIDC, billed Cloudflare CPU and real SSH-to-MANUAL acceptance remain separate evidence gaps. GPU results are unattested tripwires.
