CODE READ (tier1 result, OGKM595.84 `kern_gmmu_gv100.c:1838-1839,1881,1892,549-574`): ENGINE_ID and CLIENT are separate fault-packet fields. The engine/device table supplies the ENGINE_ID and the FIFO client decoder uses CLIENT independently. `NV_PFAULT_MMU_ENG_ID_CE0=15` is not `NV_PFAULT_CLIENT_HUB_CE0=1`. `dl_arm_body` binds COPY0, while authentic AD102 and GA102 journals both say ENGINE CE0 with different HUB clients. The proposed engine-id-to-client equality is contradicted by source and those observations, not adopted as a design change. The old guard's CE1 literal first appears in commit74aa78abe against its AD106 source-control fixture; there is no second-engine selection in the native control.
