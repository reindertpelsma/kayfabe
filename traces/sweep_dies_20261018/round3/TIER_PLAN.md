INFERRED hypotheses and falsifiers: (H1) the engine table identifies the HUB client; falsifier: engine/client are separate fault fields, or the table lacks a client field. (H2) a read-only unprivileged control supplies the missing route; falsifier: correct-size requests are refused or their published layout has no client identity. (H3) a cheap native sweep extends evidence to every rentable unmeasured target die; falsifier: unavailable offers, failed provisioning, unmatched faults, or budget refusal. Record each outcome, including unavailable dies, without borrowing a neighbor.

CODE READ (tier1 result, OGKM595.84 `kern_gmmu_gv100.c:1838-1839,1881,1892,549-574`): ENGINE_ID and CLIENT are separate fault-packet fields. The engine/device table supplies the ENGINE_ID and the FIFO client decoder uses CLIENT independently. `NV_PFAULT_MMU_ENG_ID_CE0=15` is not `NV_PFAULT_CLIENT_HUB_CE0=1`. `dl_arm_body` binds COPY0, while authentic AD102 and GA102 journals both say ENGINE CE0 with different HUB clients. The proposed engine-id-to-client equality is contradicted by source and those observations, not adopted as a design change. The old guard's CE1 literal first appears in commit74aa78abe against its AD106 source-control fixture; there is no second-engine selection in the native control.

CODE READ (tier1 broader sources): Linuxv6.16 nouveau `subdev/top/ga100.c` reads the device-info engine fault number; `subdev/fault/gv100.c` reads engine and client separately from a fault packet. Nova-Core's `gpu.rs` and module/driver source are inspected as another open-source tier1 candidate. Public sources and hashes will be recorded with the verdict; no closed-binary material is used. The independent physical route bridge remains unresolved; tier1 has not justified an admission change.

CODE READ (tier2 reason to proceed): OGKM595.84 `g_subdevice_nvoc.c:5034-5045` exports FIFO_GET_DEVICE_INFO_TABLE0x20801112 withflags0x5c040: KERNEL_PRIVILEGED, neither NON_PRIVILEGED0x8 nor PRIVILEGED0x4. `main.rs:414-430` already attempts its correct3212-byte authored request and records refusal. Its sixteen engineData words also have no HUB client field. The unprivileged per-channel GET_MMU_FAULT_INFO0x906f0106 exposes address/type/fault-type string, not CLIENT (`ctrl906f.h:191-220`). Host PCE masks are queryable but cannot alone supply the missing mapping. A fresh nobody/root probe will record actual statuses; the table's unavailability must not be reported as a zero-valued table.
